STOCK DIRECTION PLATFORM - COMMANDS
====================================

1) Windows - recommended
-------------------------
python start_run.py

or double-click:
start_run.bat

2) Git Bash / WSL / macOS / Linux
---------------------------------
./start_run.sh

or:
python3 start_run.py

3) Install manually (optional)
------------------------------
python -m venv .venv

Windows:
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pip install -e .

macOS/Linux:
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install -e .

4) Run individual pipeline stages
----------------------------------
python -m stockml.main fetch
python -m stockml.main news
python -m stockml.main features
python -m stockml.main cross-sectional
python -m stockml.main labels
python -m stockml.main baseline
python -m stockml.main train
python -m stockml.main evaluate
python -m stockml.main backtest
python -m stockml.main monitor
python -m stockml.main predict

5) Run everything
-----------------
python -m stockml.main all

6) Compare market-only vs multimodal (out-of-sample ablation)
----------------------------------------------------------
python -m stockml.main ablation

7) Start API
------------
python -m uvicorn stockml.api.server:app --host 127.0.0.1 --port 8000

8) Restart after an interrupted run
------------------------------------
python start_run.py

The launcher verifies installed package versions and repairs incompatible environments. Pipeline state/checkpoint files skip completed work and resume eligible incomplete work. Optuna uses persistent SQLite storage; LightGBM final training uses an atomic, fingerprinted booster checkpoint that can be resumed only when dataset, parameters and feature shape match.

9) Configure a point-in-time universe for historical multi-stock research
------------------------------------------------------------------------
Copy config/universe_history.json.example to a real universe-history JSON/adapter and load it in the UniverseProvider. Do not treat today's NIFTY-500 membership as historical membership.

10) FinBERT/news sentiment
------------------------------
.venv\Scripts\python.exe -m pip install -r requirements-optional.txt
Then provide timestamped article text through a licensed/news adapter and enable sentiment in configuration.

11) Track Q - Qwen reasoning rater (GPU, resumable)
---------------------------------------------------
python -m stockml.data.q0_d1 --build-pool
python -m stockml.data.q0_d1 --pilot 30
python -m stockml.data.q0_d1 --full

# Zero-touch (recommended): run this ONCE. One UAC prompt at most; it registers
# the highest-privileges scheduled task "StockML_Q0_Supervisor" (auto-start at
# logon, no time limit, auto-restart, ignore duplicate start), stops the current
# manual supervisor, starts the task, and verifies the heartbeat. After that
# there are no more UAC prompts. Keep the session logged in/locked and the
# laptop plugged in so the task can start at logon.
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_q0_task.ps1

# Inspect the setup plan without changing anything (no admin needed):
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup_q0_task.ps1 -DryRun

# Read-only status (no admin): task state, heartbeats, ledger, temp, clocks.
powershell -NoProfile -ExecutionPolicy Bypass -File .\q0_status.ps1

# Manual supervisor (fallback only): self-elevates (one UAC prompt), sets
# nvidia-smi -lgc 0,1400, watches for 89C, rests/restarts automatically,
# resets clocks on exit. Single-instance; stops any stale supervisor first.
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_q0_overnight.ps1

# Test only the clock cap (sets it, waits 5s, resets it, exits).
powershell -NoProfile -ExecutionPolicy Bypass -File .\run_q0_overnight.ps1 -TestClocks

# If the supervisor was force-closed, reset the cap manually (or reboot):
nvidia-smi -rgc

Ledger/checkpoint rules: never delete data/llm/qwen_rating_ledger.parquet,
data/llm/pool_c.parquet, or results/traces/. The ledger resumes per case.
Thermal: 80C watch, 84C prepare, 85C alarm, 87C hard stop (20-min unloaded
rest; 4 stops in a rolling hour -> 30-min cooldown), 15-min unloaded break
after every 60 min of actual GPU work (result.seconds, not wall clock),
5-second telemetry in logs/gpu_5s.csv.
